Politique de Confidentialité (RGPD)

1. Collecte des Données

Dans le cadre strict du fonctionnement du bot (Gameplay, économie, modération), nous collectons les informations suivantes associées à votre compte Discord :

  • Identifiant Utilisateur (User ID) : Donnée publique Discord nécessaire pour lier votre inventaire à votre compte.
  • Nom d'utilisateur et Avatar : Pour l'affichage dans les classements et les profils (Card, etc.).
  • Données de jeu : Solde, inventaire, XP, statistiques de commandes.

2. Finalité du Traitement

Ces données sont traitées uniquement pour :

  • Assurer la persistance de votre progression (Sauvegarde).
  • Permettre le fonctionnement des commandes d'économie et de modération.
  • Générer des statistiques globales anonymisées.

Aucune donnée n'est revendue, cédée ou partagée avec des tiers commerciaux.

3. Vos Droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (UE 2016/679), vous disposez d'un droit d'accès, de rectification et d'effacement de vos données ("Droit à l'oubli").

Pour exercer ce droit et demander la suppression intégrale de vos données de nos bases, veuillez contacter le développeur principal via le serveur de support ou par commande dédiée (si disponible).

4. Conservation des Données

Les données sont conservées tant que le bot est actif et que vous utilisez le service. Les comptes inactifs depuis plus de 365 jours peuvent faire l'objet d'une suppression automatique pour optimiser la base de données.
